# Zuvvi Foundation

Crie um novo projeto chamado Zuvvi.

Trecho da documentação desta etapa:

“Construção / front-end: Lovable (React + Tailwind). Já é a ferramenta usada no fluxo de trabalho atual; gera interfaces responsivas rapidamente, prontas para um wrapper nativo (Capacitor) publicar nas lojas no futuro.”

Neste momento, quero apenas a estrutura inicial do projeto funcionando, sem desenvolver o produto.

Não crie telas de passageiro, motorista, painel administrativo, mapas, autenticação, banco de dados, pagamentos ou integrações externas.

Não invente dados de exemplo e não crie funcionalidades provisórias.

O objetivo desta etapa é somente deixar o projeto Zuvvi criado e funcionando como base para as próximas etapas.

Não mexa em nenhuma outra tela, arquivo ou funcionalidade além do que foi pedido aqui.

This project was built with [Lovable](https://lovable.dev).

## Build with Lovable

Continue developing this project in the [Lovable editor](https://lovable.dev/projects/dc794f03-317a-47ea-9972-5291267a0af2).

- **Ship faster**: describe what you want to build and Lovable handles the code.
- **Stay in sync**: every change made in Lovable is committed straight to this repository.
- **Full ownership**: this code is yours. Push to `main` on GitHub and your changes sync back into Lovable, ready for your next prompt.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
